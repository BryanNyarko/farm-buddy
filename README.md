# FarmBuddy

## Description
FarmBuddy is a simple web-based farm task manager that helps farmers organize and track daily farming activities efficiently.

## Live Demo
https://farm-buddy-c7a84.web.app


## Tech Stack
- HTML
- CSS
- JavaScript
- Firebase (Hosting & Authentication)


## Features
- Responsive layout for mobile and desktop
- Weather API integration
- User authentication (Login / Logout validation)
- CRUD operations for managing farm tasks
